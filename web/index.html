How to read this view

Brightness shows activation. Hidden layers use a fixed exponential scale controlled by exposure. Predictions use absolute probability. Negative logits have dark fill and a bright outline.

Overview samples up to six evenly spaced channels per convolution. Focus reveals every channel. Moving cells explain the operation; they do not represent GPU execution order.

Dense lines show the top 12 terms for the selected neuron. Solid = positive weight, dashed = negative. Softmax is a shared normalization, not a learned connection.
